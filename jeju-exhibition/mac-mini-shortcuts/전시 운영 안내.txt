GeSTure Mac mini 운영

1. 시작과 종료
   최종 점검은 ‘전시 점검.command’를 더블 클릭합니다.
   실제 전시는 ‘전시 시작.command’를 더블 클릭합니다.
   최초 한 번은 이 폴더의 터미널에서 ./"전시 시작.command" --login 을 실행해
   GeSTure 저장소 쓰기 권한이 있는 GitHub 계정으로 로그인합니다.
   인터넷 운영은 ‘6/6 공개 연결 준비 완료’가 나오면 손·단어·QR 화면이 열립니다.
   ‘4/6’에서는 새 인터넷 주소와 실시간 연결을 최대 3분 기다립니다.
   대기 메시지가 나와도 창을 닫거나 시작 파일을 다시 누르지 않습니다.
   실패하면 마지막 확인 사유와 GeSTure/jeju-exhibition/data/exhibition-launcher/의
   launcher.log·tunnel.log를 확인하고 인터넷 연결을 복구한 뒤 다시 시작합니다.
   점검에서는 ‘Ollama 준비됨’이 나오면 아래 바로가기를 엽니다.
   시작 창을 열어 둡니다. 종료할 때는 그 창에서 Control+C를 누릅니다.
   재시작하거나 점검과 운영을 전환할 때는 먼저 현재 실행을 종료합니다.
   점검에서 만든 단어와 문장은 별도 기록에 저장됩니다.

2. 화면 열기
   Finder의 ‘전시 화면 바로가기’에서 실행 중인 모드의 폴더를 열고
   원하는 화면의 바로가기를 더블 클릭합니다.
   운영 모니터   http://localhost:3002/monitor
   손 화면       http://localhost:3002/display/hand
   단어 구름     http://localhost:3002/display/word
   최근 단어     http://localhost:3002/display/latest-word
   별도 구름     http://localhost:3002/word-cloud/
   관객 QR       http://localhost:3002/join/qr
   모아보기     http://localhost:3002/exhibition
   점검 중에는 위 주소의 포트를 3003으로 바꿉니다.
   모아보기의 조종기는 손가락 자리를 사용합니다. 휴대폰으로 넘기려면
   각 조종기의 ‘조종 자리 비우기’를 누르거나 탭을 닫고 15초 기다립니다.

3. 운영 모니터
   ‘전시 운영자 키.command’를 더블 클릭해 키를 복사합니다.
   모니터의 운영자 키 칸에 Command+V로 붙여넣고 ‘운영 기능 열기’를 누릅니다.
   키는 Mac mini에서만 사용합니다. 붙여넣은 뒤 일반 텍스트를 복사해
   클립보드를 바꿀 수 있습니다.
   - 초기화: 모으던 손 모양을 비웁니다. 저장된 구름은 유지됩니다.
   - 지금까지로 단어 만들기: 현재까지 모은 손 모양으로 단어를 만듭니다.
   - 내리기: 선택한 단어나 문장을 구름에서 제거합니다. 단어를 내리면 관련 문장도 내려갑니다.
   - 문장 다시 구성: 저장된 단어 두 개로 새 문장을 시도합니다.
   - 자리 반환: 연결이 꼬인 손가락의 조종 권한을 반환합니다.

4. 인터넷과 QR
   Mac mini와 관객 휴대폰 각각 인터넷이 필요합니다. 휴대폰 데이터로도 참여합니다.
   고정 입구는 https://kms8720.github.io/GeSTure/ 입니다.
   관객 QR에 손가락별 고정 주소가 들어갑니다. 준비 완료 후 휴대폰 Wi-Fi를 끄고
   다섯 QR에서 지정 손가락이 움직이는지 확인한 뒤 안내판을 인쇄합니다.
   Mac mini를 다시 시작하거나 터널이 끊겨 시작 파일을 재실행한 경우,
   준비 완료를 기다린 뒤 관객에게 같은 QR을 다시 스캔하도록 안내합니다.
   같은 네트워크에서만 운영하려면 ./"전시 시작.command" --lan 을 사용합니다.
   LAN 운영 시 .env의 PUBLIC_ORIGIN을 실제 LAN IP와 운영 포트에 맞춥니다.

5. 터미널로 실행하기
   이 작업 폴더에서 다음 명령을 실행할 수 있습니다.
   ./"전시 시작.command"
   ./"전시 점검.command"
   ./"전시 운영자 키.command"

6. 전시별 생성 단어 보관
   생성이 끝난 단어를 TXT에 한 줄씩 이어서 저장합니다.
   같은 단어가 다시 생성되면 새 줄에 기록됩니다. 구름에서 단어를 내려도 TXT는 보존됩니다.
   시작 단어 바람·종이·노래·이웃·마음은 구름에만 미리 넣었습니다.
   이번 전시 TXT는 GeSTure/jeju-exhibition/data/exhibitions/jeju-open-senses/word-cloud-words.txt 입니다.
   점검 TXT는 GeSTure/jeju-exhibition/data/rehearsal/word-cloud-words.txt 입니다.
   새 전시를 시작할 때는 이 폴더의 터미널에서 전시 ID를 지정합니다.
   ./"전시 시작.command" --exhibition next-show
   같은 ID로 다시 실행하면 같은 구름과 TXT를 이어 씁니다.
   새 ID의 TXT는 첫 단어가 생성될 때 만들어집니다.
